# exer_pratica
Há 4 níveis de exercícios práticos de C++ para a aula de Algorítimos e Lógica de Programação.

Estes desafios serão necessários para testar nossas habilidades e conhecimentos na lógica de programação, sendo necesário aplicar os conhecimentos obtidos em sala de aula, além de incentivar o estudo e pesquisa por conta própria para a resolução dos problemas.

Após a conclusão dos 4 níveis de desafio, será necessário reescrever todos os projetos em Python.
